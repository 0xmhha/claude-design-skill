tweak-panel · live design tuning

Three knobs.
No re-render.

Press T to open the panel in the bottom-right. Toggle palette, density, or accent — the layout updates live. Selections persist in localStorage so the next reload remembers them; press Reset to clear.

Step 1

Declare tweaks once

Add a <tweak-panel> at the end of <body> with one <tweak> child per design knob.

markup
Step 2

React in CSS

Each tweak writes data-tweak-<name> onto <html>; caller CSS uses the attribute selector to switch design tokens.

CSS-only
Step 3

Persist + observe

Selections survive reload via localStorage. Listen for the tweakchange CustomEvent on document if app code needs to react.

Hypothetical CTA

The page itself never imports React or any framework. The whole surface — bg, gap, radius, accent — moves on three CSS variables that the tweak-panel toggles via data-tweak-* attributes. Design exploration without a re-prompt.
